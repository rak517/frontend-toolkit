# Frontend Toolkit

반복되는 코드는 줄이고, 핵심 로직에만 집중하세요.

---

## 특징

- ✅ **선언적 API** - 구현 세부사항 없이 의도만 표현
- ✅ **타입 자동 추론** - 제네릭으로 타입 명시 불필요
- ✅ **Zero Config** - 설치 후 바로 사용

```tsx
// 보일러플레이트 없이 한 줄로
const debouncedValue = useDebounce(value, 300);
```

---

## 패키지

### [@frontend-toolkit-js/hooks](/hooks)

| 훅                     | 설명                                            |
| ---------------------- | ----------------------------------------------- |
| `useDebounce`          | 값 디바운싱                                     |
| `useDebouncedCallback` | 콜백 디바운싱 (leading, trailing, maxWait 옵션) |
| `useCalendar`          | 달력 데이터 및 네비게이션                       |
| `useIsMounted`         | 마운트 상태 확인                                |
| `useQueryParams`       | URL 쿼리 파라미터 관리                          |
| `useFunnel`            | 단계별 UI 흐름 (퍼널)                           |

### [@frontend-toolkit-js/components](/components)

| 컴포넌트           | 설명                          |
| ------------------ | ----------------------------- |
| `InViewTrigger`    | 뷰포트 진입/이탈 감지         |
| `SuspenseBoundary` | Suspense + ErrorBoundary 통합 |
| `ErrorBoundary`    | 에러 경계 처리                |

---

## 설치

```bash
pnpm add @frontend-toolkit-js/hooks @frontend-toolkit-js/components
```
