# useIsMounted

컴포넌트가 마운트되었는지 확인하는 Hook입니다. SSR 환경에서 hydration 에러를 방지하기 위해 사용합니다.

## 언제 사용하나요?

- 🖥️ SSR 환경에서 클라이언트 전용 코드 실행 시
- 📦 localStorage, sessionStorage 접근 시
- 🌐 window, navigator 등 브라우저 API 사용 시
- 🕐 클라이언트와 서버의 시간이 다를 때

## 기본 사용법

```tsx
import { useIsMounted } from '@frontend-toolkit-js/hooks';

function Clock() {
  const isMounted = useIsMounted();

  // 서버에서는 false, 클라이언트에서는 true
  if (!isMounted) {
    return <div>Loading...</div>;
  }

  // 클라이언트에서만 실행
  return <div>{new Date().toLocaleString()}</div>;
}
```

---

## 주요 사용 사례

### 1. localStorage 접근

```tsx
function UserPreferences() {
  const isMounted = useIsMounted();
  const [theme, setTheme] = useState('light');

  useEffect(() => {
    if (isMounted) {
      const saved = localStorage.getItem('theme');
      if (saved) setTheme(saved);
    }
  }, [isMounted]);

  return <div className={theme}>...</div>;
}
```

### 2. 브라우저 API 사용

```tsx
function GeolocationComponent() {
  const isMounted = useIsMounted();
  const [location, setLocation] = useState(null);

  useEffect(() => {
    if (isMounted && 'geolocation' in navigator) {
      navigator.geolocation.getCurrentPosition(pos => {
        setLocation(pos);
      });
    }
  }, [isMounted]);

  return <div>...</div>;
}
```

### 3. 서버/클라이언트 시간 차이 해결

```tsx
function ServerSafeTime() {
  const isMounted = useIsMounted();

  // 서버와 클라이언트의 시간이 다르면 hydration 에러 발생
  if (!isMounted) {
    return <div>--:--:--</div>;
  }

  return <div>{new Date().toLocaleTimeString()}</div>;
}
```

## API Reference

```typescript
function useIsMounted(): boolean;
```

### 반환값

- **타입**: `boolean`
- **서버**: `false`
- **클라이언트 (마운트 후)**: `true`

---

## 내부 동작

```tsx
export function useIsMounted(): boolean {
  const [mounted, setMounted] = useState(false);

  useEffect(() => {
    setMounted(true);
  }, []);

  return mounted;
}
```

1. 초기 렌더링: `false` 반환
2. 마운트 후 `useEffect` 실행: `true`로 변경
3. 리렌더링: `true` 반환

## 주의사항

### ❌ 남용하지 마세요

**모든 컴포넌트에 추가하면 불필요한 리렌더링이 발생합니다.**

```tsx
// ❌ Bad: 단순 렌더링에는 불필요
function SimpleComponent() {
  const isMounted = useIsMounted();
  return <div>Hello</div>;
}

// ✅ Good: 브라우저 API 사용 시에만
function BrowserAPIComponent() {
  const isMounted = useIsMounted();

  useEffect(() => {
    if (isMounted) {
      // 브라우저 API 사용
    }
  }, [isMounted]);
}
```

### 🔄 리렌더링 발생

`useIsMounted`는 **초기 마운트 시 1회 리렌더링**을 유발합니다.

```
1. 서버/클라이언트 초기 렌더: isMounted = false
2. useEffect 실행: setState(true)
3. 리렌더링: isMounted = true
```

## 대안: suppressHydrationWarning

간단한 경우 React의 `suppressHydrationWarning`을 사용할 수 있습니다.

```tsx
// useIsMounted 대신
<div suppressHydrationWarning>{new Date().toLocaleString()}</div>
```

**단, 이 방법은:**

- 경고만 숨김 (실제 hydration 불일치는 발생)
- 간단한 텍스트 차이에만 사용 권장
