# Frontend Toolkit

🚧 **Work in Progress** - 개발 중인 프로젝트입니다.

React 컴포넌트와 훅 라이브러리를 제작 중입니다.

## 🎯 목표

- 선언적 API
- 타입 안전성
- 측정 가능한 성능 개선
- 개발자 경험 향상 목표

## 📦 패키지

- `@frontend-toolkit-js/components` - React 컴포넌트 (개발 중)

## 🛠️ 개발

```bash
# 설치
pnpm install

# 빌드
pnpm build

# 개발 모드
pnpm dev
```
