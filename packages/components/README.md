# @frontend-toolkit/components

🚧 **개발 중**

React 컴포넌트 라이브러리

## 설치 (준비 중)

```bash
npm install @frontend-toolkit/components
```

## 사용법 (예정)

```tsx
import { InViewTrigger } from '@frontend-toolkit/components';

<InViewTrigger onEnter={() => console.log('보임!')}>
  <div>내용</div>
</InViewTrigger>;
```

## 컴포넌트 (개발 예정)

- InViewTrigger
- SubmitButton
- LazyImage

## 개발

```bash
pnpm dev
pnpm build
```
