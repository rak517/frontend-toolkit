# @frontend-toolkit/utils

🚧 **개발 중**

타입 안전한 유틸리티 함수 라이브러리

## 설치 (준비 중)

\`\`\`bash
npm install @frontend-toolkit/utils
\`\`\`

## 특징

- ✅ TypeScript strict mode 100%
- ✅ Zero dependencies
- ✅ Tree-shaking 지원
- ✅ 작은 번들 크기

## 유틸리티 목록 (개발 예정)

### String

- `capitalize` - 첫 글자 대문자
- `truncate` - 문자열 자르기

### Array

- `groupBy` - 배열 그룹화
- `unique` - 중복 제거

### Object

- `pick` - 속성 선택
- `omit` - 속성 제외
