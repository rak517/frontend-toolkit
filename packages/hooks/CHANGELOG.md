## [0.1.0] - 2025-11-08

### Added

- 🎉 **첫 배포!** `@frontend-toolkit-js/hooks` npm 패키지 출시
- `useCalendar` - 선언적 달력 훅
  - 42개 날짜 생성 (6주 × 7일)
  - 이전/다음 달 네비게이션
  - 오늘로 이동 기능
  - 주 시작일 설정 (일요일/월요일)
  - 요일 헤더 제공
  - TypeScript 완전 지원
  - date-fns 기반 정확한 날짜 계산

### Performance

- Bundle size: 6.0 KB (minified)

- Zero runtime overhead
